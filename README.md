# NOVA – Personal Intelligence Platform

NOVA es un asistente personal inteligente híbrido, modular y orientado a Windows.

## Características objetivo

- Funcionamiento offline
- Capacidades online cuando exista conexión
- Memoria persistente
- Inteligencia local y remota
- Interacción por voz
- Automatización
- Sistema de plugins
- Seguridad
- Interfaz principal
- Orbe permanente

## Estado

Desarrollo inicial.

## Arquitectura

NOVA utiliza una arquitectura modular basada en un Core central que coordina servicios, memoria, IA, voz, seguridad, automatización e interfaces.
